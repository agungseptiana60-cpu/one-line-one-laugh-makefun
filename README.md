One funny line, whole on its own: I told my smart speaker I was lonely; it played a sad song, then suggested I talk to a human — even the robot gave up on me. The program in `main.ts` writes that single line (124 characters) to `entry.txt` in the output directory, after checking it fits the 1–140 character gate.

## Run it

```sh
node main.ts
```

This writes `/output/entry.txt`. Outside the grader, set `MAKEFUN_OUTPUT_DIR` to choose the output directory.
